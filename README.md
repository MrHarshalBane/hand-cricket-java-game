This is a simple console-based Hand Cricket game developed in Java.

Features:
- Toss system (Heads or Tails)
- Player decision (Batting or Bowling)
- Batting logic
- Bowling logic
- Computer opponent using random numbers
- Score calculation and match result

Concepts Used:
- Java OOP
- Loops
- Conditional statements
- Random class
- Scanner for user input

This project is created for learning Java programming and basic game logic.
